# JASS Alberta Senior Companion v1.1

Expanded Windows desktop companion for Alberta seniors and family caregivers.

## v1.1 highlights

- Senior Benefits Eligibility Assistant (information screener only)
- Alberta Seniors Benefit resources
- Coverage for Seniors
- Dental and optical / seniors health resources
- CPP/OAS/GIS-oriented tax checklist
- CRA Benefits Finder
- CRA My Account
- CRA Direct Deposit
- CRA account security and scam guidance
- Emergency Centre
- Health Link 811
- Alberta Supports
- SHARP and SHARP Grant
- Seniors Property Tax Deferral
- official loan estimators
- Banking safety
- Scam Protection
- Caregiver planning
- Legal/personal planning checklist
- Important Alberta contacts
- locally saved checklist
- searchable official resource library

## Privacy

The app does not store passwords, banking credentials, SINs or full card numbers. Checklist data is saved locally under the user's Windows LocalApplicationData folder.

## Build

```powershell
dotnet restore
dotnet build
dotnet run
```

All program eligibility and benefit information should be confirmed on the linked official government pages because rules, amounts, contact information and rates can change.
